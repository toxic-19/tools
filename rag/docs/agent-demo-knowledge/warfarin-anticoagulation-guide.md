# 华法林抗凝用药指南摘要

文档类型：临床用药演示资料  
适用场景：Agent 平台演示、RAG 召回、工具协同验证

## 药物概述

华法林是一种口服维生素 K 拮抗剂，通过抑制维生素 K 依赖性凝血因子的合成发挥抗凝作用。常用于心房颤动血栓预防、深静脉血栓、肺栓塞以及部分机械瓣膜置换术后抗凝管理。

## 主要适应证

- 非瓣膜性或瓣膜性心房颤动患者的血栓栓塞预防。
- 深静脉血栓和肺栓塞的治疗及二级预防。
- 机械心脏瓣膜置换术后的长期抗凝治疗。

## 禁忌证与慎用情况

华法林禁忌或高度慎用情况包括：

- 活动性出血，例如消化道出血、颅内出血、泌尿系统活动性出血。
- 妊娠早期或计划妊娠期间，因存在致畸风险。
- 严重肝功能不全，因凝血因子合成受影响且出血风险升高。
- 明确凝血功能障碍、血小板显著减少或近期大手术后未稳定。
- 对华法林或其辅料过敏。
- 依从性差且无法规律监测 INR 的患者。

## 监测要求

- 使用华法林期间应定期监测 INR。
- 多数心房颤动患者目标 INR 通常为 2.0-3.0。
- 机械瓣膜患者目标范围可能更高，应按瓣膜类型、位置和医嘱确定。
- 出现鼻出血、牙龈出血、黑便、血尿、皮肤瘀斑明显增多时，应及时评估出血风险。

## 与 P003 演示病例的关系

P003 患者模拟信息：71 岁男性，诊断包括冠心病、心房颤动、慢性肾脏病 3 期，当前使用华法林 2.5 mg qd，并提示需要监测 INR。该患者同时有阿司匹林相关消化道出血过敏或不良反应史，因此回答中应重点提示：

- 华法林本身不是阿司匹林，但患者存在出血风险史。
- 心房颤动是华法林常见适应证之一。
- 慢性肾脏病和高龄会增加抗凝管理复杂度。
- 需要结合 INR、出血症状、肝功能和合并用药进行风险评估。

## 演示回答要点

当用户询问“P003 患者用药，看一下华法林的禁忌症”时，Agent 应结合 EHR 工具返回的 P003 用药信息和本指南内容，给出结构化回复：

- 当前用药：华法林 2.5 mg qd，需监测 INR。
- 相关禁忌：活动性出血、妊娠早期、严重肝功能不全、凝血功能障碍、过敏、无法规律监测 INR。
- 对 P003 的风险提示：高龄、慢性肾脏病、既往消化道出血相关风险，建议关注 INR 和出血表现。
