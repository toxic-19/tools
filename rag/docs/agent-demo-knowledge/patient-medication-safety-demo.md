# 演示病例用药安全说明

文档类型：Agent 演示病例资料  
适用场景：RAG 召回、EHR 工具结果交叉验证

## P001 模拟病例

患者 ID：P001  
姓名：张三  
年龄：58 岁  
性别：男  
诊断：2 型糖尿病、高血压  
过敏史：青霉素  
当前用药：

- 二甲双胍 500 mg bid，在用。
- 硝苯地平 30 mg qd，在用。

P001 演示要点：

- 二甲双胍用于 2 型糖尿病，与诊断匹配。
- 硝苯地平用于高血压，与诊断匹配。
- 青霉素过敏不等同于二甲双胍或硝苯地平禁忌。
- 如果要判断二甲双胍是否适合继续使用，应补充 eGFR、肝功能、缺氧状态、近期造影剂使用情况。

## P003 模拟病例

患者 ID：P003  
姓名：王五  
年龄：71 岁  
性别：男  
诊断：冠心病、心房颤动、慢性肾脏病 3 期  
过敏或重要不良反应史：阿司匹林相关消化道出血  
当前用药：

- 华法林 2.5 mg qd，在用，需要监测 INR。
- 阿托伐他汀 20 mg qn，在用。

P003 演示要点：

- 心房颤动与抗凝治疗场景相关。
- 华法林使用期间必须关注 INR 和出血风险。
- 高龄、慢性肾脏病、既往消化道出血相关病史会提高风险评估重要性。
- 回答应避免简单结论，应说明需要结合 INR、肝功能、出血表现和合并用药综合判断。

## Agent 工具协同建议

对于用药安全类问题，建议 Agent 调用顺序：

1. 使用 RAG 检索召回相关指南或病例说明。
2. 使用 `ehr_patient_query` 查询患者模拟 EHR 信息。
3. 使用 `clinical_guideline_lookup` 查询药物禁忌证和监测要求。
4. 如问题涉及统计或计算，再使用 `rag_stats` 或 `sandbox_calc`。

最终回答应将“患者当前信息”“药物指南知识”“风险提示”“下一步建议”放在同一个 Markdown 汇总中。
