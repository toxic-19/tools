# 硝苯地平用药安全摘要

文档类型：临床用药演示资料  
适用场景：Agent 平台演示、P001 用药清单解释

## 药物概述

硝苯地平属于钙通道阻滞剂，常用于高血压和心绞痛管理。缓释或控释制剂更常用于长期血压控制。

## 常见适应证

- 原发性高血压。
- 稳定型心绞痛或血管痉挛性心绞痛。

## 禁忌证与慎用情况

- 对硝苯地平或同类药物过敏。
- 心源性休克。
- 严重主动脉瓣狭窄。
- 低血压或血流动力学不稳定时慎用。

## 常见不良反应

- 头痛、面部潮红。
- 踝部水肿。
- 心悸或反射性心率增快。

## 与 P001 演示病例的关系

P001 患者模拟信息显示其诊断包括高血压，当前用药包括硝苯地平 30 mg qd。演示中如果用户要求“P001 患者用药清单”，Agent 可以说明硝苯地平用于血压控制，并提示关注血压、心率和踝部水肿。
